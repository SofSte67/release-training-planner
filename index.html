📘 How to use the Release Training Intake Tool

Release Training Resource Center

1. Log in first
Click on Login with Microsoft (this is a requirement for the tool to work)

2. Scrolling
Use the scrollbar to find the EDIT, DUPLICATE, and DELETE buttons. They are located at the far right.

3. Add records
Use + Add New Record to submit training sessions.

4. Edit/Delete
Only the Submitter can modify or delete a record.

5. Duplicate
Use Duplicate to quickly reuse an existing session.

6. Filters
- My Submissions: shows your records. You reset by clicking Refresh
- Product filter: search by product name. You reset by clicking Clear Filter

7. Data handling
All changes are saved (no data is overwritten).
